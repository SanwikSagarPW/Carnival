Includes the shared Spine 4.2 binary skeleton (.skel), Spine texture atlases (.atlas), PNG texture sheets, Sparky painted part atlases and PNGs, exact clip metadata, the retargeting/runtime modules, a working browser preview and the runtime license. Keep the entire folder structure. All actions share the skeleton; manifest.json selects the exported actions.

This is the rig-based animation package used by the preview. A baked frame-by-frame sprite sheet and an editable .spine project are not generated by this export.

Run a local HTTP server in this folder and open preview.html. Read README.md for the player API.
